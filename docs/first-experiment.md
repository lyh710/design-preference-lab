# First experiment: when checks and preferences disagree

**Status:** ready to run with a human. No observations have been collected here.

**Question:** Do structural checks distinguish the two layout hierarchies that a
person finds differently effective?

**Expectation:** It is possible for both candidates to have identical structural
checks while a reviewer prefers one. That would expose the scope of the checks,
not prove that either template is universally better.

**Your work:**

1. Write three fictional event briefs before generating. Include a short title,
   a long title, and one dense description.
2. Keep a fixed seed for each brief. Judge the pair before seeing metrics.
3. Record a preference and a reason. Save ties and neither outcomes too.
4. Export records. Check whether your reason concerns a measured property or a
   missing one, such as hierarchy or emotional tone.
5. Write a five-sentence memo: question, method, observation, limitation, next test.

Do not turn three personal observations into a claimed win rate for other users.
These briefs become development examples, so reserve different brief families for
later untouched test data. Do not tune on a test set and continue calling it held out.

**Interview practice:** What evidence would persuade you to use an evaluator for
selecting outputs? What additional evidence would you require before optimising a
generator directly against it?
